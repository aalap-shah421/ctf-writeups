## Format

Each writeup follows this template (see [`_template.md`](./_template.md)):

```
# Challenge Name

| Platform | Category | Points | Difficulty |
|----------|----------|--------|------------|
| ...      | ...      | ...    | ...        |

## Description
What the challenge gave you.

## Approach
What I tried, what worked, what didn't.

## Solution
The actual exploit / answer.

## What I learned
The class of bug or technique to remember.
```

## Why writeups?

Recruiters and CTF teammates want two things from a writeup: proof you can solve, and proof you can explain. Five solid writeups beats fifty mediocre ones.

I'm focused on **web exploit, OSINT, and forensics**. If you're hiring for AppSec or SOC roles, the web ones are the most relevant.
